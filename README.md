## How I build

**Product:** Django · Laravel · React · FastAPI · PostgreSQL · Celery · Tailwind · Alpine.js
**Infrastructure:** Railway · Render · Neon · AWS · Cloudflare R2 · Docker · Linux · Vercel · CI and nightly backups on GitHub Actions
**Security:** role-based access control, TOTP 2FA, rate limiting, audit logging, CSP and security headers, input validation, threat modelling

I don't treat security as a separate discipline from building. A system that
isn't secure isn't finished, so every product above ships with access control,
strict input checks and audit trails from day one rather than as a later pass.
