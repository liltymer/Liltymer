## How I build

**Product:** Django · React · FastAPI · PostgreSQL · Celery · Tailwind
**Infrastructure:** Railway · AWS · Cloudflare R2 · Linux · Gunicorn · CI on GitHub Actions
**Security:** role-based access control, TOTP 2FA, rate limiting, audit logging, CSP, threat modelling

I don't treat security as a separate discipline from building. A system that
isn't secure isn't finished, so every product above ships with per-role access
control, two-factor auth, and audit trails from day one rather than as a later
pass.
